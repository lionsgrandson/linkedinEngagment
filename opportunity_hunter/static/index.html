Recommended .env variables

OLLAMA_MODEL=qwen3.5:9b

# Recommended web search: free tier, no card required
TAVILY_API_KEY=...
HUNTER_SEARCH_PROVIDER=tavily

# No-account alternative: self-host SearXNG locally
# SEARXNG_URL=http://127.0.0.1:8888
# HUNTER_SEARCH_PROVIDER=searxng

# Optional legacy fallback
# BRAVE_SEARCH_API_KEY=...

# Optional structured jobs source
ADZUNA_APP_ID=...
ADZUNA_APP_KEY=...
ADZUNA_COUNTRY=gb

# Optional approved email sending
OUTREACH_SMTP_HOST=smtp.example.com
OUTREACH_SMTP_PORT=587
OUTREACH_SMTP_USER=...
OUTREACH_SMTP_PASSWORD=...
OUTREACH_SMTP_FROM=you@example.com

# Optional approved TTS calling
TWILIO_ACCOUNT_SID=...
TWILIO_AUTH_TOKEN=...
TWILIO_FROM_NUMBER=+1...
TWILIO_TTS_LANGUAGE=en-US

Secrets are read by the local Python process. Do not put API keys in the browser code or commit your .env.
